검증 계획

“동작한다”는 말 대신, 세 가지 근거로 확인합니다.

03검증 근거 3가지
01

입력값과 추출값 대조

근거 테스트 페이지의 title·description·canonical·H1·구조화 데이터를 기준값으로 저장합니다.
판정 기준값과 일치·누락·상이·미확인으로 구분합니다.
결과물 기준값·추출값·판정 상태 대조표

02

진단 흐름과 결과물

근거 동일 URL의 분석 시작부터 진단 결과·상세·우선순위·PDF까지 확인합니다.
판정 세 영역 표시, 상세 이동, PDF 생성 여부를 확인합니다.
결과물 주요 화면과 PDF 리포트 캡처

03

근거와 개선안의 연결

근거 각 진단 과제가 출처 URL 또는 점검 항목과 연결되는지 확인합니다.
판정 상태 구분과 카피 근거를 확인하고, 미측정 성과는 단정하지 않습니다.
결과물 진단 항목 → 근거 → 개선안 → 상태 근거표

테스트 페이지 → 기준값 저장 → BrandScan 분석 → 결과 대조 → 근거표·PDF 확인
